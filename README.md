# Komentář k zákonu č. 539/1992 Sb., o puncovnictví a zkoušení drahých kovů (puncovní zákon)

Otevřený komentář k puncovnímu zákonu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; drahé kovy a zákonné ryzosti, Puncovní úřad, puncovní kontrola a zkoušení zboží, úřední označování a závadné zboží, zkoušení ostatních výrobků, povinnosti výrobců a obchodníků, registr, puncovní inspekce a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1992-00539_2017-07-01`.
